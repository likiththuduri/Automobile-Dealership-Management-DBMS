# 🚗 Automobile Dealership Management System (DBMS)

## 📌 About the Project
The **Automobile Dealership Management System** is a DBMS course-end project developed using SQL and PL/SQL with Oracle Database. It demonstrates how automobile dealership data can be stored, managed, updated, and retrieved using database operations.

The project covers vehicle sales, database transactions, EMI calculation, salesperson reporting, triggers, and exception handling.

## 🎯 Objectives
- Create and manage relational database tables.
- Insert and manipulate dealership data.
- Retrieve information using SQL queries, joins, and subqueries.
- Create views for organized data retrieval.
- Implement PL/SQL functions and stored procedures.
- Use cursors for salesperson reports.
- Apply triggers and transaction handling.
- Handle invalid customer IDs and already-sold vehicles.

## 🛠️ Technologies Used
- **Database:** Oracle Database
- **Languages:** SQL and PL/SQL
- **Tools:** Oracle SQL Developer / SQL*Plus

## 📂 Project Structure

| File Name | Description |

## ▶️ How to Execute
1. Open Oracle SQL Developer or SQL*Plus.
2. Connect to your Oracle Database.
3. Execute `CREATING_TABLES.txt` first.
4. Execute `INSERTING_SAMPLE_DATA.txt` to populate the tables.
5. Run `DML_QUERIES.txt` and `JOINS_SUBQUERIES_VIEWS.txt`.
6. Execute `TRANSACTIONS.txt` to test transaction operations.
7. Compile and execute the function, stored procedure, cursor, and trigger scripts.
8. Run the vehicle sales scripts and test the different scenarios.

**Note:** Execute the scripts in the correct order. If a script uses an object created in another script, create that object first. The `.txt` files contain SQL commands and should be executed as SQL scripts.
